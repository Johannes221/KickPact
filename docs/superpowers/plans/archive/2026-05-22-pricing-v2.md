# KickPact Pricing v2 — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Tests are mandatory wherever they appear in the task list — TDD: write tests first, watch them fail, then implement.

**Goal:** KickPact-Pricing auf das in [docs/pricing.md](../../pricing.md) verabschiedete Konzept D umstellen — 3 Tiers (Basic / Pro / Vereinslizenz) × 3 Billing-Cycles (Monthly / Saison-Pass / Annual), Saison-Pass-Lifecycle mit Sommerpause, 5.-Spieltag-Cutoff für Saison-Pass-Kauf + Saison-Wetten, Basic-Caps (5 Sponsoren / 3 Pledge-Rules), differenzierte PDF-/Mail-Branding-Logik nach Tier.

**Architecture:** Additive Erweiterung der bestehenden Stripe + Drizzle + Inngest + Resend-Pipeline. Neue Module unter `lib/billing/`, neue Tabelle `seasons` für Cutoff-Logik, neue Subscription-Item-Logik für Cycle-Switches. Bestehende Trigger-Engine + Charge-Pipeline bleibt unverändert.

**Tech Stack:** Next.js 15 App Router, TypeScript strict, Drizzle ORM (Postgres), Stripe (Subscriptions + Subscription-Pause-API), Inngest (Cron-Jobs für Pause/Resume), Resend (Reply-To pro Tier), Vitest.

**Source of Truth:** [docs/pricing.md](../../pricing.md) — §11 "Implementations-Konsequenzen" listet alle Code-Änderungen. Werte (Preise, Caps, Cutoffs) sind dort autoritativ.

**Referenz-Spec:** [docs/superpowers/specs/2026-05-19-kickpact-v1-design.md](../specs/2026-05-19-kickpact-v1-design.md) — §6.8 + §8.4 werden in Section 1 dieses Plans ersetzt.

**Out of Scope:** Pricing-Landing-Page (`app/(marketing)/preise/page.tsx`) wird parallel von einem separaten Agent mit `ui-ux-pro-max` gebaut. Custom-Domain-Feature (Vereinslizenz-only) ist v2. Konsolidierte Sammel-PDF, Master-Admin-Cockpit, Cross-Team-Sponsor-View — siehe Spec-Sections, eigene Pläne.

- **Phase A** — Stripe-Setup + Spec-Update (Section 1) — Foundation, blockt alles andere
- **Phase B** — DB-Schema + Migration (Section 2) — blockt Sections 4–11
